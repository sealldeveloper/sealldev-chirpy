SECedu Week 1 2024 - Challenge Writeups

Posted Sep 12, 2024
By sealldev 26 min read

I am participating in the SECedu CTF 2024 online and found some of the challenges surprisingly difficult. I am playing in a team of 4 (MQCybersec Trojans) and we were in 1st this week. The following is a writeup of the challenges I beat and how to crack them :p. Big thanks to the authors of the challenges from the various universities, and to my teammates: tulip, finnersio and soap!

Week 1

Easy

Encoded, secret message?

While inspecting logs, we found a message being sent across our internal network. What could this be???

This challenge we were given a string of characters: 籜籎籌籎籍籞粄籮籷籬簹籭籲籷籰籨籶簽籼籽簼类籨簹类籨籼簹籶簼籽籱簺籷籰粆.

Plugging this into Cyberchef, I remember generally that ROT8000 converts to these kinds of characters. I am correct and it decodes to the flag.

DCode’s Cipher Detection also picks it up as ROT8000.

Flag: SECEDU{enc0ding_m4st3r_0r_s0m3th1ng}

int checkIfA(char *username, char *password);
void printFile();

int main() {
    int admin = 0;
    char protect[] = {'\0', 'A'};
    char username[10];
	char password[5];

    printf("This is the company's employee portal.\n");
    printf("---------------------------------------------\n");
	printf("Please enter your name:\n");
    gets(username);
    printf("Please enter your password:\n");
    gets(password);


    if (strcmp(username, "AAAAAAAAAA") == 0 || strcmp(password, "AAAAA") == 0) {
        printf("What a strange username or password!\n");
        return 1;
    }

    if (admin != 0 && protect[0] == '\0' && protect[1] == 'A') {
        printf("Welcome admin!\n");
        printFile();
        return 0;
    }

    printf("Employee not found!\n");
    return 1;
}

void printFile() {
    FILE *file = fopen("flag.txt", "r");
    int c;
    while ((c = fgetc(file)) != EOF) { fputc(c, stdout); }
    fclose(file);
}

We can see that the admin variable is initially 0, there are two protect values of \0 and A, and there is a set limit on the username and password (10 and 5 respectively).

The check then checks if the username matches AAAAAAAAAA or the password matches AAAAA, if it does it exits the program.

The next check is for if the user is an admin:

  • The admin value needs to be a non-0 value
  • The protect[0] must be \0
  • The protect[1] must be A

Thats, it..?

We can do a Buffer Overflow to break this challenge.

The strcmp is only checking for an exact match, so we could use B’s or a’s or anything but A’s.

We can then overflow to rewrite the admin value, but we need to preserve the values of protect.

So, we can start with the overflow: bbbbbbbbbb, then add the protect values \0 and A, then changing admin to a 1.

The value is bbbbbbbbbb\0A1, we can inject the NULL value to netcat with CTRL+SHIFT+2, we can then ignore the password value as its never used apart from the strcmp check.

Medium-ware

We’ve managed to dump some firmware from an experimental AVR8-driven PLC. Our developer had hardcoded a particular string inside, and promises that it’s “secure enough”.

Find a way to extract this string. This is the flag in its entirety.

This is expected to be quite a difficult challenge for week 1.

Hint: Look for references to DAT_mem, revealing the location hiding with offset 0x02d2. This will also yield a xor operation, 0x97, that is used to decode a string at the end of the code segment.

Hint: There is some rubbish data following a predicatable pattern once the xor key is applied.

Hint: There is random data inside the flag. i.e: SECEDU{<front>_<random_data>} This is intentional, keep going until you find a closed bracket }.

This challenge was the most brutal one for the week, a PLC based challenge (which I have next to no experience in, apart from SCONES 2024 which had the same author as the hardware challenges there for this challenge).
