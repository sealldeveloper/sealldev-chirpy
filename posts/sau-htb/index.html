Sau HackTheBox Machine - Writeup

Posted Jan 2, 2024
By sealldev 3 min read

A retiring linux easy machine, trying to do one a day!

Machine created by: sau123

Recon

Starting with a nmap scan of the IP, we see 3 open ports.

Lets edit our /etc/hosts and add a new entry.

1

10.10.11.224 sau.htb

Trying to load sau.htb:80 failed, so I take a look at port 55555 and load sau.htb:55555 and see a request-baskets instance.

Exploitation

I look for any CVEs related to request-baskets and find a PoC for CVE-2023-27163 which is an SSRF vulnerability. We can maybe access that port 80 service we can’t seem to reach.

> Creating the "bameet" proxy basket...
> Basket created!

> Authorization: NM2Y9TQKkreZV-x6IjfYLsjs55W-g6JJ3YlDeB6b1kSc

Visiting the request bin shows us a broken instance of Mailtrail (v0.53).

Initial Access & User Flag

Looking online there is a vulnerability for Mailtrail, and find a PoC which is an RCE.

I set up a reverse shell listener…

Looking at GTFOBins entry for systemctl under the Sudo permission, there are some exploits.

The most promising one is option (c) due to our limited sudoers line.
